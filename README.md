# Web Designs

Librería personal de diseños reutilizables.

- `tokens/`: colores, fuentes, espaciados y sombras, un archivo por proyecto.
- `componentes/`: piezas sueltas (tarjetas, botones, navbars...).
- `paginas/`: secciones o páginas completas.
